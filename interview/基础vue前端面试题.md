#### 3、`v-for` 使用 `key` 有什么作用？使用 `key` 需要注意什么？

不增加 key 的时候，数据变化采用的是“就地更新“的策略，更新每个数据。

增加 key 当数据进行插入，移动，删除等，会通过 `diff` 算法识别需要变动的数据位置进行更新，而不是全量更新，更高效的处理 DOM 的更新和保证正确性。

key 需要保持唯一性，否则会出现数据错乱的情况，key 以 `string` 类型为好，不建议放对象作为key，不建议以数组的 index 作为 key

#### 5、watch 和 计算属性 `computed` 有什么区别？

- `computed` 用于计算已有数据的计算和更新，数据会被缓存，只有依赖的数据更新才会被重新计算，适合有返回值的场景，
- watch 用于监听某个数据的变化，进而执行对应的操作，适合无返回值的场景。

#### 8、vuex 什么时候考虑用 vuex

#### 9、vuex 的核心属性有哪些？分别有什么用

- state：存放状态
- getters：计算属性，用于对 state 进行加工处理，返回结果
- mutations：用于变更 state，不能直接变更 state，只能通过 mutations 来变更 state，不能有异步操作
- actions：用于处理异步操作，不能直接变更 state，只能通过 mutations 来变更 state，可以有异步操作
- modules：模块化，将 store 分割成多个模块，每个模块拥有自己的 state、getters、mutations、actions，可以有嵌套模块

#### 10、vue 的生命周期

- beforeCreate：new Vue()之后触发的第一个钩子，在当前阶段data、methods、computed以及watch上的数据和方法都不能被访问。
- created：在实例创建完成后发生，当前阶段已经完成了数据观测，也就是可以使用数据，更改数据，在这里更改数据不会触发updated函数。可以做一些初始数据的获取，在当前阶段无法与Dom进行交互，如果非要想，可以通过vm.$nextTick来访问Dom
- beforeMount：发生在挂载之前，在这之前template模板已导入渲染函数编译。而当前阶段虚拟Dom已经创建完成，即将开始渲染。在此时也可以对数据进行更改，不会触发updated
- mounted： 在挂载完成后发生，在当前阶段，真实的Dom挂载完毕，数据完成双向绑定，可以访问到Dom节点，使用$refs属性对Dom进行操作。
- beforeUpdate： 发生在更新之前，也就是响应式数据发生更新，虚拟dom重新渲染之前被触发，你可以在当前阶段进行更改数据，不会造成重渲染。
- updated： 在更新完成之后被触发，也就是虚拟dom重新渲染完成之后被触发，此时数据已经更新，但页面尚未更新。
-beforeDestroy： 发生在实例销毁之前，在当前阶段实例完全可以被使用，我们可以在这时进行善后收尾工作，比如清除计时器。
- destroyed： 在实例销毁之后被触发，此时实例已经完全被销毁，无法使用。
