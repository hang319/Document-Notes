# 项目业务代码学习

## VO（对象类）

#### 1、`@JsonFormat`

通常用于处理 json 序列化的数据

如果需要对 `Date` 类型进行处理，也可以通过 `@JsonFormat` 自定义时间的格式。

也可定义价格或者枚举类的数据。

```java
@JsonFormat(pattern = "yyyy-MM-dd HH:mm:ss", timezone = "GMT+8")
private Date createTime;

@JsonFormat(shape = JsonFormat.Shape.STRING)
private BigDecimal price;
```

#### 2、`DateTimeFormat`

对时间日期格式进行转换

#### 3、`@ApiModelProperty`

Swagger 或 Springfox 库中的一个注解，用于在生成 API 文档时，为模型的属性添加描述信息

#### 4、`@EncryptField`

`import com.fjean.common.util.encryption.EncryptField`

自定义注解，用于标记需要加密的字段。序列化和反序列化自动加解密。
