# 事务管理

事务是一组操作的集合，要么同时成功，要么同时失败。

### 操作

- 开启事务：start transaction / begin;
- 提交事务：commit;
- 回滚事务：rollback;

`@Transactional`

### 开启事务管理日志

```yml
logging:
    level:
        org.springframework.transaction: debug
```

### 事务进阶

#### 1、rollbackFor

默认情况下，只有出现 RuntimeException 时，事务才会回滚，rollbackFor 属性也哦那个鱼控制出现何种异常类型，回滚事务。

```java
@Transactional(rollbackFor = Exception.class)
```

#### 2、propagation

事务传播行为：指的是当一个事务方法被另一个事务方法调用时，这个事务方法应该如何进行事务控制。


```java
@Transactional(propagation = Propagation.REQUIRED)
```

- REQUIRED: 需要事务，有则加入，无则创建新事务
- REQUIRES_NEW: 新事务，无论有无，总是创建新事务
