- Mybatis Framework
- MySQL Driver

创建 `pojo.User` 的实体类，并生成 getset 和构造函数

建立数据库链接，在 `application.properties` 文件下写入数据库连接四要素

```bash

spring.datasource.url=jdbc:mysql://localhost:3306/db02
spring.datasource.username=root
spring.datasource.password=qaz123456
```

2、创建 `mapper.UserMapper` 接口编写SQl 请求。

```java
@Mapper 
public interface UserMapper {

    // 查询用户信息
    @Select("select * from user")
    public List<User> list();

    @Delete('delete form emp where id = #{id}')
    public void delete(Integer id);

    @Options(keyProperty="id", useGeneratedKeys=true) // 返回id
    @Insert("insert into emp(...) values(...)")
    public void insert(Emp emp);

    @Update("update emp set username = #{username}, name = #{name} where id = #{id}")
    public void update(Emp emp);


    // 需要开启 mybatis 驼峰命名的自动开关
    @Select("select * from emp where id=#{id}")
    public Emp queryById(Integer id);

    @Select("select * from emp where name like concat('%', #{name} ,'%') and gender = #{gender} and entrydate between #{begin} and #{end} order by update_time desc")
    public List<Emp> listByOptions(String name, short gender, LocalDate begin, LocalDate end);
}
```

### XML 映射文件

- XML 映射文件的名称与Mapper接口的一致，并且将XML映射文件和Mapper接口放置在相同包下(同包同名)
- XML 映射文件的namespace 属性为 Mapper 接口全限定名一致
- XML 映射文件中 sql 语句的id 与 Mapper 接口中的方法名一致，并且保持返回类型一致。

**下载 MybatisX**

```xml
<?xml version="1.0" encoding="UTF-8" ?>
<!DOCTYPE mapper PUBLIC "..." />

<mapper namespace="com.itheima.mapper.mapper.EmpMapper">

    <select id="listByOptions" resultType="com.itheima.pojo.Emp">
        select * from emp where name like concat('%', #{name} ,'%') and gender = #{gender} and entrydate between #{begin} and #{end} order by update_time desc
    </select>

    <select id="listByOptions" resultType="com.itheima.pojo.Emp">
        select * from emp 
        <where> 
        <if test="name != null">
           name like concat('%', #{name} ,'%')
        </if>
        <if test="gender != null">
           and gender = #{gender}
        </if>
        <if test="begin != null and end != null">
           and entrydate between #{begin} and #{end}
        </if>
        </where> 
    </select>

    <update id="update">
        update emp 
        <set>
            <if test="username != null"> username=#{username}, </if>
        </set>
        where id = #{id}
    </update>

    <delete id="deleteByIds">
        delete from emp where id in 
        <foreach collection="ids" item="id" separator="," open="(" close=")">
            #{id}
         <foreach>
    </delete>

    <!-- sql 片段的抽取和引用 -->

    <sql id="commonSelect">
        select * from emp 
    </sql>

    <!-- 引用 -->
    <include refid="commonSelect"></include>
</mapper>
```

### 配置文件参数管理

`applications.properties`

```properties
alityun.oss.entryPoint=oss-cn-beijing.aliyuncs.com
```

使用 

```java

@Value("${alityun.oss.entryPoint}")
private String endpoint;

@ConfigurationProperties(prefix = "alityun.oss")
```
