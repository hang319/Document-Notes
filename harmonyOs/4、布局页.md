# 布局页

如果想设置设置 `Row` 或者 `Column` 的组件有间隔可以采用： `{space: 10}`


### 模拟器设置网络权限

在 `系统-安全-层序访问控制-应用全选管控-申请应用权限-声明权限-应用权限列表-开放权限（系统授权）`

```js
{
     "requestPermissions": [
      {
        "name": "ohos.permission.INTERNET"
      }
    ],
}
```

### List 横向滚动

`.listDirection(Axis.Horizontal)`

list 默认会占用一个比较大的高，可以自动设置一个高度来控制

### 元素裁剪

`.clip(true)`

### 设置文本过长省略

```js
 Text(item.name)
    .maxLines(2)
    .textOverflow({ overflow: TextOverflow.Ellipsis })
```
