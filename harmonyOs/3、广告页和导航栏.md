# 广告页

## 页面生命周期

| 生命周期方法 | 调用时机 | 说明 |
|-------------|---------|------|
| `onPageShow()` | 页面显示时 | 页面每次显示时都会触发，包括从后台切换到前台 |
| `onPageHide()` | 页面隐藏时 | 页面每次隐藏时都会触发，包括切换到后台 |
| `onBackPress()` | 用户点击返回按钮时 | 返回true表示自己处理返回逻辑，false表示使用默认返回逻辑 |
| `onMenuPress()` | 用户点击菜单按钮时 | 仅在支持菜单的设备上触发 |
| `onRefresh()` | 页面刷新时 | 当页面需要刷新时触发 |
| `onNewRequest()` | 收到新的页面请求时 | 当页面收到新的Intent时触发 |

## 组件生命周期

### 基础组件生命周期

| 生命周期方法 | 调用时机 | 说明 |
|-------------|---------|------|
| `aboutToAppear()` | 组件即将出现时 | 组件即将显示在页面上时触发 |
| `aboutToDisappear()` | 组件即将消失时 | 组件即将从页面上移除时触发 |

### 自定义组件生命周期

| 生命周期方法 | 调用时机 | 说明 |
|-------------|---------|------|
| `onPageShow()` | 页面显示时 | 自定义组件所在页面显示时触发 |
| `onPageHide()` | 页面隐藏时 | 自定义组件所在页面隐藏时触发 |
| `onBackPress()` | 用户点击返回按钮时 | 自定义组件所在页面返回时触发 |

## 应用生命周期

| 生命周期方法 | 调用时机 | 说明 |
|-------------|---------|------|
| `onCreate()` | 应用创建时 | 应用首次启动时触发，只调用一次 |
| `onDestroy()` | 应用销毁时 | 应用被系统销毁时触发 |
| `onForeground()` | 应用切换到前台时 | 应用从后台切换到前台时触发 |
| `onBackground()` | 应用切换到后台时 | 应用切换到后台时触发 |

## 生命周期执行顺序

### 应用启动流程
1. `onCreate()` - 应用创建
2. `aboutToAppear()` - 组件即将出现
3. `onPageShow()` - 页面显示

### 应用切换到后台
1. `onPageHide()` - 页面隐藏
2. `onBackground()` - 应用切换到后台

### 应用切换到前台
1. `onForeground()` - 应用切换到前台
2. `onPageShow()` - 页面显示

### 应用销毁
1. `onPageHide()` - 页面隐藏
2. `aboutToDisappear()` - 组件即将消失
3. `onDestroy()` - 应用销毁
